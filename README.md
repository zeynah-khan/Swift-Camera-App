# 📸 iOS Camera App

A custom iOS camera application built using **SwiftUI** and **AVFoundation**.  
This project demonstrates camera session management, custom UI design, and UIKit integration within a SwiftUI architecture.

---

## ✨ Features

- 📷 Photo capture using AVFoundation  
- 🔁 Front and back camera switching  
- ⚡ Flash modes (Off / On / Auto)  
- 🖼 Live thumbnail preview of the latest photo  
- 🗂 Full-screen gallery with horizontal swipe navigation  
- 🔍 Native pinch-to-zoom using UIKit (`UIScrollView`)  
- 🗑 Delete images directly from the gallery  
- 🧱 Clean MVC-style folder structure  

---

## 🛠 Tech Stack

- **SwiftUI** – UI layout and state management  
- **AVFoundation** – Camera capture session handling  
- **UIKit (UIScrollView)** – Native zoom and pan behaviour  
- **ObservableObject & @Published** – Reactive state updates  
- **Git & GitHub** – Version control
